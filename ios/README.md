# LocalAI iOS launcher

This is a thin native SwiftUI launcher. The visible interface comes from the shared Compose Multiplatform framework generated by the root `shared` module.

Open `LocalAI.xcodeproj`. The Xcode build phase runs the Gradle framework integration automatically.

The project links the official llama.cpp XCFramework and bridges its streaming
Swift engine into the shared Kotlin `LocalLLMEngine`.

To activate local inference:

1. Download `gemma-3-1b-it-Q4_K_M.gguf`.
2. Rename it to `model.gguf`.
3. Put it at `LocalAI/Models/model.gguf`.
4. Build and run from Xcode.

The model is copied into the app bundle automatically. With no model present,
the app starts with the mock engine.
